# Простая реализация алгоритма сжатия с применением Преобразования Барроуза-Уиллера и Кодированием Длин Серий

## Описание
Реализация сжатия и восстановления строки алгоритмами BWT и RLE

## Структура кода
### Директория `BWT_RLE_Lib`
+ Файл `BWTClass.cs` - описание класса алгоритма Преобразования Барроуза-Уиллера и логика его работы
+ Файл `RLEClass.cs` - описание класса алгоритма Кодирования Длинами Серий и логика его работы
+ Файл `BWT_RLE_DecoratorClass.cs` - описание класса сжатия и восстановления строки алгоритмами BWT и RLE и логика его работы
### Директория `BWT_RLE_Experiments`
+ Файл `Program.cs` - экспериментальное использование написанных классов

## Запуск
+ Скачать и установить актуальную версию .NET
+ Скачать исходный код
+ Запустить исполняемый файл  `BWT_RLE_Experiments.exe`, находящийся в директории `BWT_RLE_Experiments\bin\Release`
